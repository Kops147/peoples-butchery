How this works: This tool scans all products in Firestore, detects which ones have local image files in assets/img/food/, and lets you upload them to Firebase Storage. After upload, Firestore is updated automatically.

Before running: Make sure Firebase Storage rules allow writes: allow write: if request.auth != null; — set this in Firebase Console → Storage → Rules.
